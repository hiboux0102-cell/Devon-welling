# Devon Welling — V1 (site statique)

Site statique V1 pour le cabinet d'avocats "Devon Welling" — esthétique dorée basée sur le logo fourni.

Contenu
- index.html — page d'accueil
- about.html — équipe
- rules.html — domaines de pratique
- contact.html — contact + formulaire (Formspree placeholder)
- css/styles.css — styles principaux (gold on black)
- assets/ — logo.svg (approximation) et favicon.svg

Remarques
- J'ai remplacé les mentions liées au roleplay par un contenu professionnel et réaliste adapté à un cabinet d'avocats.
- Vérifie et remplace les coordonnées (téléphone, adresse, email) dans contact.html par les informations réelles.
- Remplace le champ action du formulaire dans contact.html par ton endpoint Formspree ou backend pour recevoir les messages.

Déploiement
- Déployer sur GitHub Pages : créer une branche `gh-pages` ou utiliser la branche `site-v1` et activer GitHub Pages dans les paramètres.
- Ou héberger sur Vercel / Netlify.

Prochaine étape
- Souhaites-tu que j'importe le logo PNG fourni (image 1) dans le repo et l'utilise directement à la place du SVG ? Réponds "importe le PNG" et je l'ajouterai.
