# Devon Welling — V1 (site statique)

Site statique V1 pour le cabinet RP "Devon Welling" (GTA RP) — esthétique dorée basée sur le logo fourni.

Contenu
- index.html — page d'accueil
- about.html — équipe
- rules.html — règles RP
- contact.html — contact + formulaire (Formspree placeholder)
- css/styles.css — styles principaux (gold on black)
- assets/ — logo.svg (approximation) et favicon.svg

Remarques
- J'ai ajouté un logo SVG stylisé (assets/logo.svg) et un favicon. Si tu veux que j'ajoute l'image PNG/raster que tu as uploadée (me l'autorises), je peux l'importer dans le repo comme assets/logo.png et remplacer l'SVG.
- Remplace le champ action du formulaire dans contact.html par ton endpoint Formspree si tu veux le recevoir par email.

Déploiement
- Déployer sur GitHub Pages : créer une branche `gh-pages` ou utiliser la branche `site-v1` et activer GitHub Pages dans les paramètres.
- Or héberger sur Vercel / Netlify.

Prochaine étape
- Si tu veux que j'importe le logo PNG fourni (image 1) dans le repo et l'utilise directement, confirme "importe le PNG" et je l'ajouterai.
